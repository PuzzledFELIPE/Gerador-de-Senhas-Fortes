# Gerador de Senhas Seguras

Um aplicativo em Python com interface gráfica (Tkinter) para gerar senhas fortes e aleatórias.

## Como Acessar
1. Caso já tenha o Python em sua máquina
    1. Clone este repositório:
        ```bash
        git clone https://github.com/PuzzledFelipe/Password-Generator.git

    2. Entre na pasta 
        ```bash
        cd Password-Generator

    3. Execute o Programa
        ```bash
        python Password_Generator.py

2. Caso não tiver o Python em sua máquina
    1. Acesse o executável na pasta "dist" no diretório

## Como Usar
1. Escolha o tamanho da senha (12 a 30 caracteres)

2. Geração automática de senhas com letras, números e símbolos

3. Interface gráfica simples e intuitiva
